# Moving Multiple Repos Content Into One

## Overview

This lab demonstrates how to move multiple small projects from their repositories into one general repo. 

## Objectives

- Clone all small repos + python-practices
- Delete the ".git" file and modify the "README.md" files of each directory
- Move directories into python-practices
- Push the new python-practices to the server
- Delete empty repositories left behind

## Technologies

- Git / CMD
- Github
- VsCode

## Lessons Learned

- Clone repos
- Push local repos to github
- Authenticate with gitHub

## Future Improvements

- Don't create separate repositories for small similar projects, instead have them all under one repository for better readability and easier access.
